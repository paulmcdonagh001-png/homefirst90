Privacy

HomeFirst90 can be used for free without creating an account.

  • Free planning tools store your setup plan, moving-out total, household-bills estimate and pre-move household profile locally in your browser using localStorage.
  • If you buy HomeFirst90 Complete, Stripe processes the payment and provides HomeFirst90 with payment status, customer reference and the email used at checkout.
  • Complete stores your household planning data, task progress and purchase tracking in HomeFirst90's hosted database so it can be used across devices.
  • A private Complete access code is stored in your browser and can be used to open the same household on another device. Treat that code like a password.
  • No advertising or affiliate tracking is active at the moment.
  • HomeFirst90 records minimal first-party usage events such as page viewed, tool used and Complete checkout clicks so we can understand whether the service is useful. These events use a temporary browser-session identifier; our analytics database does not store your IP address or use advertising fingerprints.
  • No third-party analytics tracker has been added.

You can remove local data by clearing site data for HomeFirst90 in your browser. For paid-data deletion or payment questions, use the HomeFirst90 support details shown on your Stripe payment receipt.
