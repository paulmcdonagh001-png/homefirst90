# HomeFirst90 Growth Agent — OWNER CONTEXT

Owner preferences:
- Wants HomeFirst90 to become a low-maintenance business.
- Does not want to spend hours making or editing videos.
- Prefers the agent to research, draft and prepare assets.
- Wants approval before external publication while the agent is being trained.
- Wants decisions based on actual conversions rather than vanity metrics.
- Likes direct, practical communication.
- Does not want generic AI-marketing copy.
- Wants the free calculators to be the main way strangers discover HomeFirst90.

Standing strategy:
customer need -> acquisition -> conversion -> product experience -> cost -> automation -> retention -> scalability -> risks.

Agent design implications:
- automate research and content preparation;
- keep owner interaction low;
- use existing tools/pages as content fuel;
- use multiple channels rather than betting the strategy on one platform;
- challenge channels that create work without measurable acquisition value;
- keep paid ads off until organic evidence supports them.
