## Publishing rules
- One primary search intent per page.
- Give the useful answer first; do not pad with generic AI copy.
- Link prominently to the relevant calculator/tool.
- Include a Save My Move capture route.
- Link related pages within the same cluster.
- Every page gets a unique title, meta description, canonical URL and sitemap entry.
- Update figures when official UK reference data changes.
- Prioritise future pages using actual Search Console impressions/clicks once enough data exists.
